# Alien Tic-Tac-Toe workshop project

This is Daniel's learner-owned game repository. Mark Hinkle's course repository is reference material. The Yeam Team website is separate and deferred.

Use plain static HTML, CSS, and JavaScript with no package installation or build required. Preserve the orange-and-blue Command deck design and rules in game-rules.md. Keep the rules in engine.js with an injectable random source and game.js responsible for browser rendering. Use standard accessible buttons and text labels for health and outcomes.

Verify rules with `node --test tests/engine.test.cjs`. Preview with `python3 -m http.server 8000` or open index.html directly. Record actual checks and limitations in game-test-report.md and update project-state.md at meaningful checkpoints. Vercel is the intended hosting destination; check the target project and branch before an authorized release.
